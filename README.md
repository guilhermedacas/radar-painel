# Radar de Imóveis — Painel

Painel web (celular) do [Radar de Imóveis](https://github.com/guilhermedacas/radarimoveis): login, filtros por pessoa, favoritos e convites.

Publicado via GitHub Pages em https://guilhermedacas.github.io/radar-painel/

O arquivo `index.html` é uma cópia de `painel/index.html` do repositório principal. Só contém a chave pública (anon) do Supabase; a segurança vem das regras do banco.
